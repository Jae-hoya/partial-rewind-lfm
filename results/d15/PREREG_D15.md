# D15 사전등록 — Test A 빈 답안(215/600)의 원인 진단

2026-11-02. **진단 스크립트 실행 전에 커밋한다.** 호출 0 — 캐시 미스는 예외로 막는다.

## 질문

Test A 의 빈 branch 실행(215/600)은 (A) 해당 sub-question 의 근거 청크가 12000자
컨텍스트 상한(`branch.max_context_chars`)에 잘려 프롬프트에 들어가지 못했기 때문인가,
(B) 근거가 들어갔는데도 모델이 기권했기(`branch.py` ANSWER 프롬프트의 "or leave the
text empty") 때문인가.

## 재현 조건 (전제)

Test A(`results/test_a/20260829-041445`)를 캐시만으로 재생한다. 50토픽 × 4 branch × 3라운드.
재생한 (query, round, branch) 별 `degraded` 가 `waste_ratio.csv` 와 **600/600 일치**하고
캐시 미스가 0 이어야 진단이 유효하다. 하나라도 어긋나면 판정하지 않고 보고한다.

## 단위와 변수

- 단위: branch-round 안의 sub-question (sq).
- 자기 청크: 그 sq 의 검색 질의(anchor + sq)가 돌려준 top-k 청크 전부 (다른 sq 가 먼저 가져와 중복 제거된 것 포함).
- **노출(primary)**: 자기 청크 중 하나 이상이 컨텍스트에 본문 200자 이상으로 실렸다.
- 결과: sq 의 답 text 가 비었다.

## 판정 규칙 (A형)

E1 = 노출 없는 sq 의 빈 답 비율, E0 = 노출 있는 sq 의 빈 답 비율, RR = E1 / E0.
query 단위 군집 부트스트랩 2000회(seed 42)로 RR 의 95% CI 를 낸다.

**A형** ⇔ RR ≥ 2 이고 RR 의 95% CI 하한 > 1. 그 밖은 **B형**.
노출 없는 sq 가 30개 미만이면 판정 불가로 보고한다.

## 함께 보고 (판정에 쓰지 않음)

- sq 위치(index)별 층화한 E1, E0. 뒤쪽 sq 가 원래 어려울 수 있는 교란을 보기 위함.
- 빈 branch 215건 중 모든 sq 가 노출된 비율 — 노출되고도 전부 비운 branch 수.
- 컨텍스트에 실린 청크 수, 잘린 청크 수, 검색된 청크 수 분포.
- 노출 기준을 "본문 1자 이상" / "청크 전체" 로 바꾼 민감도.
- 출력 절단: answer 의 finish_reason=length 건수.
