## 2. 고정 임계, 주 집계(양방향 max) — 원 논문 구성

양성률 % (N1 / P1 / P2). 요약 `per_checkpoint.<ck>.max.fixed`.

| 체크포인트 | τ=0.70 | τ=0.95 |
|---|---|---|
| facebook/bart-large-mnli (원본) | 26.37 / 97.83 / 0.00 | 16.16 / 97.83 / 0.00 |
| roberta-large-mnli | 26.37 / 100.00 / 0.00 | 9.36 / 97.83 / 0.00 |
| cross-encoder/nli-deberta-v3-large | 37.18 / 97.83 / 0.00 | 35.24 / 97.83 / 0.00 |
| cross-encoder/nli-deberta-v3-base | 34.87 / 100.00 / 0.00 | 31.23 / 100.00 / 0.00 |

**원 구성(max, τ∈{0.70, 0.95})에서는 네 체크포인트 모두 N1 양성률이 기준 5% 를 넘는다** (최저 9.36%).
P1(부정문) 재현율은 전부 97.83% 이상, P2(paraphrase) 의 contradiction 양성률은 전부 0.00% 다.
즉 "같은 sub-question 의 claim 쌍이 contradiction 으로 자주 잡힌다"는 관찰은 bart 하나의 특이성이 아니다.
특히 DeBERTa-v3 두 체크포인트는 bart 보다 N1 양성률이 높다.

## 3. 스윕(0.50–0.99) × 집계(max/min/mean) — 사전 등록 판정

사전 등록 정의: 한 구성에서 **P1 ≥ 80% 이고 N1 ≤ 5%** 면 "쓸 만한 트리거".
요약 `usable_configs` 에 **16개 구성**이 이 조건을 만족했다 → `generalizes_no_usable_config: false`.
**사전 등록 기준으로 "어떤 임계·집계도 쓸 만한 트리거를 주지 않는다"는 결론은 일반화되지 않는다.**

체크포인트·집계별 "P1 ≥ 80% 중 N1 최소" 지점 (요약 `best_under_P1ge80`, 전부 τ=0.99 에서 나왔다):

| 체크포인트 | max | min | mean |
|---|---|---|---|
| bart-large-mnli | N1 8.51 / P1 93.48 | **N1 1.82 / P1 91.30** | **N1 2.55 / P1 91.30** |
| roberta-large-mnli | **N1 2.92 / P1 93.48** | **N1 0.85 / P1 86.96** | **N1 0.97 / P1 89.13** |
| nli-deberta-v3-large | N1 29.53 / P1 97.83 | N1 13.49 / P1 93.48 | N1 14.95 / P1 93.48 |
| nli-deberta-v3-base | N1 24.79 / P1 97.83 | N1 10.57 / P1 91.30 | N1 10.94 / P1 93.48 |

(굵게 = 기준 충족.) 충족 구성은 bart 5개(min τ 0.97–0.99, mean τ 0.98–0.99),
roberta 11개(max τ 0.98–0.99, min τ 0.95–0.99, mean τ 0.96–0.99)이며 DeBERTa-v3 두 개는 0개다.
충족 구성의 N1 양성 쌍 수는 7–41 / 823, P1 검출 수는 40–45 / 46 이다 (요약 비율 × n 으로 환산).

요점:
- **원본 체크포인트(bart)에서도 집계를 max 에서 min/mean 으로 바꾸고 τ 를 0.97 이상으로 올리면 기준을 충족한다.**
  원 논문은 max 집계만 시험했으므로, 원 결론은 "bart + max" 구성에 대해서만 성립한다 (bart+max 최선 N1 8.51%).
- 체크포인트 의존성이 크다: roberta 는 max 로도 충족하고, DeBERTa-v3 는 어떤 시험 구성으로도 충족하지 못한다.

## 4. 이 결과를 과대해석하지 말아야 할 이유

1. **표본 내 선택**: 충족 구성은 4 체크포인트 × 3 집계 × 50 임계 = 600 구성 중에서 같은 자료로 골랐다.
   별도 검증 세트가 없으므로 이 임계들은 낙관적으로 편향됐을 수 있다.
2. **P1 은 쉬운 상한**: 부정문은 `gpt-5.4-nano` 의 기계적 부정이다(`gate_p1p2.csv`). 실제 관점 간 모순은
   이보다 미묘하며, τ≥0.95 의 높은 임계가 그런 모순을 잡는다는 근거는 이 실험에 없다. P1 은 46 쌍뿐이라
   80% 기준(37/46) 근처의 차이는 몇 쌍 수준이다.
3. **N1 은 라벨이 없다 (R1-5)**: 같은 답안·같은 sub-question 의 claim 이 반드시 양립한다는 보장은 없다.
   그러므로 **N1 비율은 양성률이지 위양성률이 아니다.** 낮은 N1 양성률이 "오경보가 적다"를 뜻하는지
   "실제 모순을 놓친다"를 뜻하는지는 이 실험으로 구분할 수 없다. 이 실험은 어떤 라벨도 검증하지 않는다.
4. 범위: 위 4 체크포인트, 3 집계, 이 임계 격자, N1 823 · P1 46 · P2 50 쌍, 15 토픽, `C3_partial_heldout`.
   시험하지 않은 체크포인트·집계·자료로 확장하지 않는다.
5. **격자 경계**: 모든 "P1 ≥ 80% 중 N1 최소" 지점이 격자 상단 τ=0.99 에 놓였다. 격자가 내부 최적점을 찾지 못했다는 뜻이며,
   0.99 초과의 더 촘촘한 격자는 사전 등록하지 않았으므로 보고하지 않는다.
6. 이 실험은 관계 모듈을 켜고 VERIFY 를 실제로 돌린 것이 아니다. 충족 구성이 파이프라인 안에서 유용한지는 미검증이다.

## 5. 탐색 항목 — 체크포인트 간 N1 플래그 일치 (τ=0.95, max)

| bart-large-mnli | 133 |
| roberta-large-mnli | 77 |
| nli-deberta-v3-large | 290 |

넷 모두 플래그 54쌍, 하나 이상 플래그 364쌍. 체크포인트 쌍별 Jaccard 0.2325–0.5764
(최고 deberta-large|deberta-base 0.5764, 최저 roberta|deberta-base 0.2325).
일치는 부분적이다: 플래그의 상당수는 체크포인트마다 다르지만, 네 모델이 공통으로 강하게(>0.95) 모순이라 하는
54쌍이 있다. 이 54쌍에 실제 모순이 섞였을 가능성(R1-5, 체크리스트 C-7 "생성기가 근거 불일치를 섞는다")은
**가설일 뿐이며**, 텍스트를 `results/d20/n1_consensus_flagged.csv` 에 저장했다. 라벨은 붙이지 않았다.

## 6. 보조 — MiniCheck (트리거 후보 아님)

`lytang/MiniCheck-Flan-T5-Large` 는 지지 확률만 낸다 (요약 `minicheck_descriptive`).
양방향 support 최댓값의 중앙값: N1 0.035, P1 0.026, P2 0.971. support 최댓값 ≤ 0.5 비율: N1 96.23%, P1 100%, P2 0%.
N1 과 P1 이 모두 "지지 안 됨"으로 몰리므로 MiniCheck 는 모순과 중립을 가르지 못한다 — 사전 등록대로 트리거 판정에서 제외했다.
(N1 쌍이 대부분 서로를 함의하지 않는 별개의 사실이라는 점과는 일관된다.)

## 7. 원고 반영 제안 (판단은 사용자·공저자)

- 삭제/수정 대상: "어떤 임계·집계도 적합한 트리거를 주지 않는다"류의 일반 진술. **D20 에서 표본 내·사전 등록 기준으로 반박된다** (§4 의 제약 포함).
- 대체 문안 방향(초안): "원 구성(bart-large-mnli, 양방향 max, τ=0.70)에서 같은 sub-question claim 쌍의 26.4% 가
  contradiction 으로 판정되었고, 이 경향은 시험한 네 NLI 체크포인트 모두에서 max 집계·τ∈{0.70, 0.95} 일 때 유지되었다
  (N1 양성률 9.4–37.2%). 다만 min/mean 집계와 τ≥0.95 의 높은 임계에서는 bart·roberta 가 사전 등록 기준(P1≥80%, N1≤5%)을
  표본 내에서 충족했고, DeBERTa-v3 는 충족하지 못했다. 이 임계는 같은 자료에서 고른 것이고 P1 은 기계적 부정문이며
  N1 은 라벨이 없으므로(양성률이지 위양성률이 아니다), 관계 모듈을 끈 결정은 '트리거가 불가능하다'가 아니라
  '검증된 트리거를 확보하지 못했다'로 서술한다."
- 이 수정은 R1 의 "VERIFY 비활성(26.4% FP)" 지적과도 맞물린다: "FP" 표현은 "양성률"로 바꿔야 한다.
